# Practice-problems

A structured collection of Data Structures and Algorithms (DSA) problems solved as part of my preparation for software engineering placements, coding assessments, and technical interviews. The repository primarily uses Java to practice problem-solving, with concepts including Arrays, 2D Arrays, Strings, Searching, Sorting, Bit Manipulation, Recursion, Linked Lists, Stacks, Queues, Hashing, Trees, Graphs, and Dynamic Programming. I focus on understanding the logic behind each problem, identifying common problem-solving patterns, writing clean and readable solutions, and analyzing time and space complexity. The main tech stack and learning tools include Java, Java Collections Framework, IntelliJ IDEA/VS Code, Git & GitHub, LeetCode, GeeksforGeeks, and online coding platforms, with problems ranging from beginner fundamentals to placement-oriented interview questions. This repository serves as a record of my consistent DSA practice and ongoing journey toward becoming placement-ready.
